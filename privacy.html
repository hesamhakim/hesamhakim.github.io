Privacy policy

PhenoMotion video uploader — last updated 21 November 2026.

The short version

This application is used by one person to upload their own videos to their own YouTube channel. It has no other users, no server, no database and no analytics. It collects nothing about anybody, and it sends nothing to anyone except YouTube.

What it accesses, and why

  • youtube.upload — to upload a video file to the signed-in user's own channel, and to set its thumbnail.
  • youtube.force-ssl — to attach a subtitle track to a video the application has just uploaded. YouTube's API accepts caption uploads under no narrower permission.

It uses these permissions for nothing else. It does not read, modify, or delete any other video, comment, playlist or subscriber information.

What is stored, and where

After the user signs in, Google issues an OAuth token. That token is written to a single file on the user's own computer, readable only by that user's account. It is never transmitted anywhere except back to Google when refreshing the sign-in. No video, caption, title or description is stored anywhere but on the user's own machine and on YouTube.

What is shared

Nothing. No data is sold, rented, shared with third parties, used for advertising, or used to train any model.

Limited use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Deleting the token file on the user's own computer has the same effect locally.

Contact

Questions about this policy: see the contact address on the Google consent screen for this application.
