# hesamhakim.github.io

This repository exists only to hold Google Search Console's domain-verification file for
`hesamhakim.github.io`, so the domain can be listed as an authorized domain for an OAuth app.

It deliberately has **no `index.html`**, so the root of the site serves a 404 rather than any page, and
`.nojekyll` stops GitHub Pages turning this README into one.

The site itself lives at <https://hesamhakim.github.io/phenomotion/>, from the `phenomotion` repository.
